# Explainable DR Rural Screening

## Problem
Reliable diabetic retinopathy screening in rural areas is limited by poor retinal-image quality, limited specialist availability, and deployment constraints.

## Proposed Solution
A MATLAB-based explainable AI screening workflow that performs:

1. Image quality assessment
2. Image enhancement
3. DR severity grading
4. Lesion detection
5. Explainable AI using Grad-CAM
6. Confidence-based triage
7. Ophthalmologist teleconsultation
8. Resource and workflow simulation

## Workflow

Fundus Image
→ Quality Check
→ AI Screening
→ Explainability
→ Confidence & Risk
→ Smart Triage
→ Ophthalmologist Review
→ Final Decision
